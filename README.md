# ReplayRecorder

Made by MGP.

ReplayRecorder is a Windows app for saving instant replays and recording sessions. Download the setup file from the [Releases page](https://github.com/mgproductions61-afk/ReplayRecorder-Releases/releases).

The installer is not code-signed, so Windows may show a security warning.
